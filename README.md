## Sobre mim

Sou designer e desenvolvedor front-end. Trabalho com identidade visual, sites, páginas de conversão e interfaces, conectando decisões de design às necessidades das pessoas e aos objetivos de cada projeto.

Implemento experiências responsivas com HTML, CSS, JavaScript, TypeScript, React e Next.js. Uso Figma para a direção visual, Git para acompanhar a evolução do código e Vercel para publicação.

- **Design:** identidade visual, interfaces, layouts responsivos e sistemas visuais.
- **Desenvolvimento:** HTML, CSS, JavaScript, TypeScript, React, Next.js e Tailwind CSS.
- **Forma de trabalhar:** entender o problema, organizar o conteúdo, desenhar, implementar, testar e publicar.
